photon-fdtd: a verified 2D FDTD solver and a robust inverse-designed bend

Result. The best validated 80 x 80 inverse-designed bend (adjoint seed 5, shared 20 x 20 representation) meets the release gates on the training spectrum, the 61-wavelength held-out spectrum and the half-cell grid (worst case over eroded, nominal and dilated masks: IL 0.1718 dB, RL 22.99 dB held-out; gates IL < 0.50 dB, RL >= 22 dB), and beats the best tested conventional bend (bezier:0.45, robust IL 0.3306 dB) by 0.1595 / 0.1588 / 0.1611 dB (training / 61 held-out / half-cell grid), more than the largest measured grid change (0.0026 dB). The full-resolution phase 1 run (phase1 r_f 6; bend80_phase1.gds, kept as the record of the unconstrained-grid failure mode) meets the release gates on the training spectrum, the 61-wavelength held-out spectrum and the half-cell grid (worst case over eroded, nominal and dilated masks: IL 0.2737 dB, RL 22.31 dB held-out; gates IL < 0.50 dB, RL >= 22 dB), but does not beat the best tested conventional bend (bezier:0.45, robust IL 0.3306 dB) by the required 0.10 dB: the gain is 0.0569 / 0.0569 / 0.0575 dB. The release design was chosen by the lowest training-set robust J among the designs that meet every gate; the protocol did not name it in advance, and the choice does not use held-out data.

Limitations & Failure Modes

  • 2D TMz versus 3D. The model has one field component (Ez), an infinitely tall slab and no substrate. A 3D silicon-on-insulator bend has a finite height, substrate leakage and polarisation coupling; none of them is modelled. The 3.48:1 index contrast without a substrate probably makes tight bends look better than in 3D (not tested).
  • Stair-stepping. The geometry is a binary pixel mask on the solver grid, and the exported layout keeps the same cell-edge steps. The half-cell grid re-rasterises the same design and gives the measured grid change above; it does not remove stair-stepping.
  • Modelled bias versus real process variation. The eroded and dilated masks are a uniform ±1-native-cell morphological change of the design box only. The slabs are not biased. Real processes have non-uniform edge bias, corner rounding, sidewall angle, line-edge roughness and thickness variation; none of them is in the model.
  • Negative benchmark results. CMA-ES never reaches T2 (J <= best baseline - 0.10 dB) in any run; one-step PPO never reaches T2 (J <= best baseline - 0.10 dB) in any run.
  • Known failures kept in the record. Phase 1: 23 of 25 scored masks of the r_f 6 run failed the geometry gates; the chosen design is the scored mask of it 3, of 96 iterations. The final relaxed iterate (post-hoc diagnostic, not a candidate) reaches a robust IL of 0.0877 dB and RL 24.41 dB held-out, but its nominal mask has 1 floating silicon component, 8 width and 11 gap violations (minimum width 2 cells, minimum gap 3 cells): the projection-based length-scale control did not hold. Earlier, a nominal-only 80 x 80 run (Stage 5 stretch, 0.0376 dB) also failed the 5-cell width rule; it is not a release target. Release design (adjoint seed 5): the nominal mask meets every geometry rule, but the biased masks do not: eroded layer 4 width and 0 gap violations, dilated layer 2 width and 2 gap violations (reported, not gated).
  • Not verified. RTL: the SystemVerilog stencil is bit-exact with its software reference in Verilator on two test cases only; no synthesis figures. No Lean proof in this release candidate. The layout scale is illustrative. The independent layout reader is a second implementation by the same author, not a commercial DRC tool.
